# AI Candidate Ranking System

## Overview
This project ranks candidates for an AI Engineering role using a rule-based scoring framework.

## Features
- Experience-based scoring
- Skill matching
- Career relevance analysis
- Behavioral signal evaluation
- AI and Retrieval bonuses
- Top 100 candidate ranking
